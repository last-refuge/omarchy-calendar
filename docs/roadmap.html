02
Active phase

Complete calendar management

Finish the ordinary work of managing time: edit, move, resize, delete, recur, invite, and recover—online or off.

Edit existing events

  • Prefilled native composer from the event inspector
  • Optimistic SQLite updates and ETag-protected Google PATCH
  • Three-way merge and automatic HTTP 412 recovery
  • Safe named conflicts when both sides change the same field

Move & resize

  • Drag between times, days, weeks, and month cells
  • Resize duration from event edges
  • Keyboard equivalents for every pointer action
  • Coalesce rapid drag mutations before upload

Delete & undo

  • Optimistic delete with timed undo
  • Durable Google delete mutation
  • Restore on failure and handle remote absence
  • Delete keyboard shortcut

All-day & multi-day

  • Date-only storage without UTC conversion
  • Multi-day spans in every view
  • Move between timed and all-day sections
  • Boundary and timezone tests

Timezones

  • IANA timezone picker and recent choices
  • Original zone plus local equivalent
  • DST gaps and repeated-hour handling
  • Cross-timezone test matrix

Recurrence & exceptions

  • ✓ Series identity, exception metadata, RRULE parsing, and DST-safe local expansion
  • ✓ Daily, weekday, weekly, monthly, yearly, custom-interval, and count-limited creation
  • ✓ Edit one occurrence, this and following, or the entire series with parent-ETag protection
  • ✓ Undoable cancellation for one occurrence, this and following, or the entire series

Rich event details

  • ✓ Reminders, descriptions, locations, meeting links, and guests
  • ✓ Organizer identity and attendee response state
  • ✓ Busy/free, privacy, and guest permissions
  • ✓ Calendar moves with organizer, recurrence, event-type, and destination capability checks

Quick entry

  • ✓ Natural-language input for relative dates, weekdays, times, and durations
  • ✓ Explicit interpretation preview before creation
  • ✓ Ctrl+K flow into the full composer for keyboard-first correction

Search depth

  • ✓ Title, description, location, calendar, organizer, and attendee search
  • ✓ Date, calendar, organizer, and response filters
  • ✓ Match highlighting and keyboard result actions

Mutation reliability

  • ✓ Create, update, delete, and move queue operations
  • ✓ Coalescing, strict ordering, exponential retry, and queue inspection
  • ✓ Manual retry, discard, and edit-or-discard conflict resolution
Exit conditionOrdinary personal calendar management no longer requires opening Google Calendar.

How to maintain this roadmap

Every deliverable card has one status in the HTML: data-status="done", active, planned, or blocked. Change that one value when work moves, then update data-last-updated on the <body> element. The badges, totals, completion percentage, phase summaries, and filters are calculated automatically. Add new work by copying any card that contains data-roadmap-item.
